# rs-music

简体中文 | [English](README.md)

rs-music 是一个用 Rust 和 egui / eframe 编写的原生桌面音乐播放器，参考了 [LX Music](https://github.com/lyswhut/lx-music-desktop) 的使用体验。

## 快速开始

安装稳定版 Rust。Linux 还需要 ALSA 开发库和 `pkg-config`。

```sh
cargo run --release
```

Linux 默认使用原生 Wayland。纯 X11 环境可设置 `RS_MUSIC_WINDOW_BACKEND=x11` 显式选择 X11。

Linux 通过 Fontconfig 查找系统字体和中文回退字体。可在「设置 → 界面 → 界面字体」切换，选择会在重启后保留。

Linux 默认关闭窗口后在后台继续运行。托盘可恢复窗口或退出应用，可在「设置 → 界面 → 关闭窗口时」改为直接退出。桌面需要有系统托盘，例如 Waybar 的 `tray` 模块。托盘不可用时，关闭窗口会退出。

Linux 支持 MPRIS。窗口打开或隐藏到托盘时，都可以用媒体键或 `playerctl` 控制播放，例如 `playerctl -p rs_music play-pause`、`playerctl -p rs_music next` 和 `playerctl -p rs_music stop`。

## 使用指南

| 页面 | 功能 |
| --- | --- |
| 曲库 | 导入文件或递归扫描文件夹，也可以直接拖放。支持按文件名过滤、播放和加入队列。 |
| 队列 | 管理同一队列里的本地和在线歌曲。播放模式可在设置中切换。 |
| 音乐大厅 | 浏览网易云、QQ 音乐、酷狗和酷我的热门曲目和歌单。打开歌单可把整张歌单加入队列，也可跳转到原站。 |
| 音乐搜索 | 按歌曲或歌手搜索，回车可提交。支持切换平台和音质。搜索栏上方可复用或清空历史关键词。 |
| 设置 | 更改界面语言和播放模式，导入、切换或移除音源，管理搜索配置和自动换源。 |

底部播放栏分别显示播放和缓冲进度。有音频总大小时显示缓冲百分比，未知总大小时显示已接收的数据量。在线播放采用边下边播，音频下载完成且总时长可用时可以拖动进度条。启用自动换源后，当前音源启动失败时会按成功次数从高到低尝试其他支持该平台的 LX 音源。同分保持原顺序。音频完整下载后才计入实际使用音源的成功次数，命中本地缓存不计入。切换成功时播放栏会显示实际使用的音源。

### 歌词

播放栏在歌曲名两侧显示封面和当前歌词。点击底部封面可查看大字完整歌词。点击播放栏的「字幕」可打开透明置顶窗口，上下两行交替显示当前句和下一句。当前句按时间戳扫色，下一句到点后在原位开始扫色。可在「设置 → 界面」调整缩放，点击百分比恢复 100%。带时间戳的歌词会随播放高亮和滚动，音频可跳转时也可以点击歌词行定位。

- 本地歌曲读取同目录下同名的 UTF-8 `.lrc` 文件，例如 `歌曲.flac` 对应 `歌曲.lrc`。
- 网易云歌曲按歌曲 ID 获取歌词。其他在线平台会尝试用歌曲名和歌手匹配网易云版本。
- 在线歌曲优先使用平台提供的封面，缺少时尝试匹配网易云版本。本地歌曲支持同名的 `.jpg`、`.jpeg`、`.png` 文件和音频中嵌入的 JPEG 或 PNG 封面。没有可用封面时，播放器会生成默认封面。

### 在线音源

音乐搜索默认使用 iTunes，结果可打开对应网页。要在应用内播放，可在「设置 → 音源管理 → 导入音源…」加载 LX 脚本或提供播放地址的 JSON 配置。

LX 支持 UTF-8 编码的 `.js`（最大 2 MiB）和 `.lx.json` 导出文件。酷狗（`kg`）、酷我（`kw`）、咪咕（`mg`）、QQ 音乐（`tx`）和网易云音乐（`wy`）均有内置搜索。播放能力和音质取决于所选脚本及上游服务。也可以在音源管理中为当前平台导入 JSON 搜索配置。

以下 JSON 示例使用占位地址。

```json
{
  "name": "My music catalog",
  "search_url": "https://music.example.com/search",
  "query_parameter": "q",
  "results": "/tracks",
  "title": "/title",
  "artist": "/artist",
  "audio_url": "/stream"
}
```

应用用 GET 发出搜索请求。`results` 指向结果数组，其他 JSON 指针相对于单条结果。若接口只返回歌曲 ID，可配置 `"track_id": "/id"` 和 `"playback": {"url": "https://music.example.com/play", "id_parameter": "id", "audio_url": "/url"}`，由应用另行获取播放地址。JSON 音源的音频地址使用 HTTPS，单首在线音频的大小上限为 40 MiB。

## 缓存和自动保存

- **音频缓存**。时长达到 20 秒的在线音频完整下载后会写入磁盘，保留 14 天。重播时优先读取有效缓存或已保存的音频，可跳过音源解析和音频下载。
- **自动下载歌曲和歌词**：可在「设置 → 下载」分别开关，默认均开启，下载目录默认为系统音乐目录（通常是 `~/Music`）。歌词与音频并行获取，保存为同目录下同名的 `.lrc` 文件。音频缓冲完成后，可在播放栏选择「保存到本地」或「不保存」。两项都未选择时，应用在歌曲自然播完后按自动下载歌曲设置处理。
- 不足 20 秒的曲目跳过自动保存。缓冲完成后可点击「保存到本地」，启用了歌词保存时会一并保存歌词。
- **LX 初始化缓存**。可缓存的配置响应没有过期时间，重启后可以复用。歌曲的播放地址按需解析。
- **清理缓存**。在「设置 → 缓存」可按写入时间清理音频、音乐大厅和 LX 初始化缓存，支持最近 5、10、30 分钟、最近 1 小时、最近 24 小时或全部时间。

Linux 默认存储位置如下。设置了 XDG 目录时，应用使用对应的位置。

| 内容 | 位置 |
| --- | --- |
| 设置、音源、曲库与队列 | `~/.local/share/rs-music/state.json` |
| 搜索历史 | `~/.local/share/rs-music/search-history.json` |
| 音频缓存 | `~/.cache/rs-music/audio/` |
| LX 初始化缓存 | `~/.cache/rs-music/lx-init-v1/` |
| 音乐大厅缓存 | `~/.cache/rs-music/discovery-v1/` |

音乐大厅的热门曲目、网友歌单列表和歌单内曲目各自独立分页。打开歌单可查看封面、平台提供的介绍和原站链接。榜单、歌单列表和详情缓存 30 分钟，歌单封面缓存 7 天。点击「刷新」可更新当前平台的榜单和网友歌单所在页，或更新已打开的歌单详情。

## 终端日志

日志写到标准错误。网络错误会记录出错的操作、目标主机和可用的底层原因，例如 DNS 解析失败、连接超时或 TLS 证书错误。收到异常响应时会记录 HTTP 状态或响应解析位置。请求 URL 的路径、查询参数和凭据会被隐藏。可用下面的命令收集调试日志。

```sh
RUST_LOG=warn,rs_music_gui=debug,rs_music_core=debug cargo run 2>rs-music.log
```

## 开发

[模块与维护指南](docs/architecture.md) 包含按功能查找代码的索引、在线播放流程和配置兼容性说明。

- `crates/rs-music-core` 负责平台目录、LX 脚本、音频请求与歌词解析。
- `crates/rs-music-gui` 负责原生窗口、页面、播放与歌词同步。
- `crates/rs-music-storage` 负责配置、搜索历史、音频缓存与歌曲、歌词的本地保存。

```sh
cargo fmt --all -- --check
cargo test --workspace
cargo build --workspace
```

后续计划包括自建歌单、媒体键和逐字歌词。
